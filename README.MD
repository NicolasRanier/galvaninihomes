💡 Sobre o projeto

O Galvanini Homes é uma landing page criada com o objetivo de apresentar uma hospedagem, destacando seus ambientes, comodidades, localização e informações de contato.

O projeto foi desenvolvido com auxílio do Lovable, seguindo uma proposta visual definida pelo cliente.

Também utilizo este projeto como oportunidade de aprendizado e prática em desenvolvimento web, buscando compreender melhor a estrutura da aplicação e aprofundar meus conhecimentos em HTML, CSS e JavaScript.

📱 Responsividade

A interface foi desenvolvida para proporcionar uma experiência de navegação adaptável a diferentes tamanhos de tela, incluindo dispositivos móveis e computadores.
